About This Website

Development Tools

  • HTML5 for website content and page structure.
  • One external CSS stylesheet, located at CSS/style.css.
  • Responsive layouts for desktop, tablet and mobile devices.
  • CSS hover effects and animations.
  • HTML details elements for expandable recovery procedures.
  • No JavaScript, databases or backend services.

Keeping Policies Updated

  • The proposed IT Manager approves policy changes.
  • Each policy has an owner, document ID and version number.
  • The technical team updates and checks pages before publication.
  • Employees are informed when approved policies change.
  • The previous approved version is kept for possible recovery.
